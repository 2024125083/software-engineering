# Easy Kiosk Python Demo

사회적 약자를 위한 쉬운 키오스크 설계서를 바탕으로 만든 수업 시연용 프로토타입입니다.

## 실행 방법

1. VS Code에서 이 폴더를 엽니다.
2. Python 3가 설치되어 있는지 확인합니다.
3. VS Code 터미널에서 아래 명령을 실행합니다.

```powershell
python app.py
```

별도의 패키지 설치는 필요하지 않습니다.

## 시연 기능

- 일반모드 / 이지모드 선택
- 큰 글씨, 큰 버튼, 자막과 Windows 음성 안내
- 이용 빈도 기반 추천 메뉴
- 메뉴 선택 → 확인 → 주문의 3단계 흐름
- 직원 호출 및 중복 호출 방지
- 비식별 이용 로그 저장
- 간단한 관리자 통계 화면

`data` 폴더의 JSON 파일은 앱을 실행하면서 자동 생성됩니다. 실제 결제, 기존 키오스크 연동, 직원 알림 전송은 시연용 화면으로 대체되어 있습니다.
