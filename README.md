# easy 키오스크 시스템

## 1. 프로젝트 소개

사회적 약자와 디지털 취약계층도 쉽게 사용할 수 있는 easy 키오스크 시스템을 설계하고 개발하는 소프트웨어 공학 프로젝트입니다.

본 프로젝트는 음식점, 카페, 공공기관 등에서 사용되는 키오스크의 복잡한 UI 문제를 개선하고, 

사용자가 메뉴 선택부터 결제까지 직관적으로 진행할 수 있도록 하는 것을 목표로 합니다.

## 2. 주요 기능

- 쉬운 메뉴 탐색 기능
- 큰 글씨와 단순한 화면 구성
- 주문 내역 확인 기능
- 결제 진행 기능
- 관리자용 메뉴 관리 기능
- 사용자 오류 방지를 위한 확인 절차 제공
